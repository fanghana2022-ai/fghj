## 三、 個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

依作業規則，同一人在同一場活動重複出現只算一位參加者，且只收一次該場費用。測試一的桌遊整理串列 `['amy', 'ben', 'amy', 'cora']` 雖然有 4 筆紀錄，但 `'amy'` 重複出現兩次，實際不重複的參加者只有 `'amy'`、`'ben'`、`'cora'` 共 3 人，因此桌遊費用以 `3 × 120 = 360.00` 元計算。

- **直接拆成 `list`**：**保留**了原始輸入的順序與重複出現的次數（方便觀察誰重複報名或報名先後），但**失去**了「唯一性／去重」的效果，且無法直接做交集、聯集、差集運算。
- **再轉成 `set`**：**保留**了不重複的參加者元素，並能進行集合比較（交集、聯集、差集）；但**失去**了原本的排列順序與重複次數資訊，若要依字母順序呈現或做切片，還需要再經過 `sorted()` 轉成串列。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

在測試三中，桌遊去重集合為 `{'amy', 'ben', 'cora'}`（3 人），電影去重集合為 `{'amy', 'ben', 'cora'}`（3 人）。兩場集合完全相等，因此交集 `board_set & movie_set` 為 `{'amy', 'ben', 'cora'}`（共同人數 3 人），聯集 `board_set | movie_set` 也為 `{'amy', 'ben', 'cora'}`（總不重複人數 3 人），兩個方向的差集皆為空集合（顯示為 `[]`）。

- **報名人次**：依規則為兩場各自去重後的人數相加，每人參加兩場算兩人次，因此為 `3 + 3 = 6` 人次。
- **總應收**：兩場分別按各自去重人數計費，桌遊應收 `3 × 120 = 360.00` 元，電影應收 `3 × 80 = 240.00` 元，合計 `360 + 240 = 600.00` 元。
